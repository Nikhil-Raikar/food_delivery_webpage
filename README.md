# Food Delivery Webpage

A beautiful food delivery website created using HTML and CSS.

## 📖 Description

A first food delivery web page showcasing a responsive design with menu items, services, and delivery information. Built entirely with HTML and CSS.

## 🔗 Live Website

**[Visit the Food Delivery Website](https://nikhil-raikar.github.io/food_delivery_webpage/)**

## 🛠️ Technology Stack

- HTML5
- CSS3

## 🚀 Features

- Responsive design that works on all devices
- Beautiful and modern UI
- Food menu display
- Service information sections
- Contact and delivery details
- Smooth navigation

## 📁 Project Structure

```
food_delivery_webpage/
├── index.html          # Main HTML file
├── style.css           # Styling
└── README.md           # This file
```

## 💡 How to Use

1. Visit the live website link above, or
2. Clone the repository and open `index.html` in your browser
3. Browse through the menu items and services
4. Explore different sections of the website

## 📝 Installation (Local)

```bash
# Clone the repository
git clone https://github.com/Nikhil-Raikar/food_delivery_webpage.git

# Navigate to the project directory
cd food_delivery_webpage

# Open index.html in your browser
```
